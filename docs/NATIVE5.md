# Native5 historical note

Native5 included the first standalone CCUIToggleModule candidate and added `CFBundleSupportedPlatforms = [iPhoneOS]` to its bundle. The module still did not appear in Settings on the user's device. The source and behavior remain unconfirmed as a functioning CC integration.

Native7 removes that module, all related build targets and the CCSupport dependency. QuietHosts is now the standalone app only. The native5 parser addition for Quantumult X exact `HOST` rows, unsupported-rule accounting, home/UI styling, root-only DNS child and document-picker cancellation lineage is retained in later versions.

Native5 build receipt: GitHub Actions run `37709099058`, commit `46c61784bb08fb756bd73df6be489f6a9d853e38`. Its artifact is historical and is not the current product candidate.
